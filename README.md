# Maestro — Personal Bio & Portfolio

Минималистичный персональный сайт-визитка (био) в стиле **Dark Minimalism / Glassmorphism**.

## Стек и особенности
- **HTML5 / CSS3 / JavaScript (Vanilla)** — чистый, лёгкий код без лишних тяжёлых фреймворков.
- **Типографика**:
  - `Driagwa` — стилизованный акцидентный шрифт заголовков.
  - `JetBrains Mono` — технологичный моноширинный шрифт для кода и описаний.
- **Дизайн**:
  - Тёмная монохромная палитра (`#000000`, акценты `#ffffff`).
  - Эффект матового стекла (glassmorphism) на карточках и плашках.
  - Кастомный пиксельный курсор (`cursor.png`, `cursor-pointer.png`).
  - Вертикальная бегущая строка `HE MAESTRO`.
  - Динамическая подгрузка проектов с GitHub API.

## Структура сайта
1. **Hero**: Приветствие, ключевой стек (Telegram Bots, Discord Bots, Web/Landing, Python, Node.js, TypeScript).
2. **Projects**: Витрина актуальных репозиториев и проектов с авто-синхронизацией.
3. **Socials**: Ссылки на Telegram-канал, TikTok и GitHub.
4. **Footer**: Финальное прощальное слово и статус.
